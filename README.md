# Blackjack Web Game

A browser-based Blackjack game originally developed as a team programming project for a college course.

## Project Context

This project was originally created collaboratively as a class assignment. The team worked together on the Blackjack game and its browser-based interface.

My primary contribution to the original project was the event-driven audio and visual system, which changes the atmosphere of the game based on consecutive player wins.

After completing the course, I revisited the repository to organize the project files and prepare the original version for archival before beginning an independent reconstruction of the project.

## Features

The original version includes:

- Blackjack gameplay with Deal, Hit, and Stand actions
- Player betting and balance tracking
- Dealer behavior based on hand value
- Ace value adjustment
- Blackjack and standard win conditions
- A consecutive-win system that changes the game's audio and visual intensity
